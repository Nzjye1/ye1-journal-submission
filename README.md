# Ye1 医学论文投稿助手

**从选刊、准备材料到投稿进度管理，协助推进医学论文投稿。**

- 根据稿件情况协助选刊并核对目标期刊的要求。
- 整理投稿材料、作者信息和声明，按授权协助投稿与进度管理。
- 具体期刊要求、投稿权限及实际状态以当时核实结果为准。

试着说：“帮我根据这篇论文选刊，并整理目标期刊要求的投稿材料。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-journal-submission-skill.zip)，解压后保留完整的 `ye1-journal-submission` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-journal-submission` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-journal-submission/SKILL.md)。
