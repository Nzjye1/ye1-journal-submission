# Ye1 医学论文投稿助手

**从选刊、投稿准备到投稿进度管理，为医学论文作者组织全流程工作。**

面向支持 Skill 指引的各类 AI Agent，用自然语言交办任务。

## 能做什么

- **选刊：**结合研究内容和投稿目标，比较期刊范围、收录、分区、费用、审稿信息和相关论文。
- **投稿准备：**按期刊要求整理稿件、图表、标题页、投稿信和适用声明；保存并复用已确认的作者信息。
- **推荐审稿人：**根据论文方向查找候选专家，整理研究匹配、机构和公开联系方式。
- **协助投稿：**使用 Agent 的浏览器或电脑操作能力填写投稿信息、上传文件并核对预览。
- **多篇管理与进度查询：**整理各篇稿件、期刊、投稿记录和待办，按需查询审稿进展和设置提醒。
- **投稿邮件：**根据需要接收并整理获授权的投稿邮箱中与稿件有关的期刊来信。
- **投稿后处理：**协助处理退回补正，整理修回材料，准备拒稿后的改投，以及录用后的校样核对。

## 安装到你的 Agent

将下面这段话发给你的 Agent：

> 请从 https://github.com/Nzjye1/ye1-journal-submission 获取 Ye1 医学论文投稿助手。读取 `skills/ye1-journal-submission/SKILL.md`，按照当前 Agent 支持的方式安装完整 Skill 文件夹并检查所需工具，然后告诉我如何开始使用。

也可以下载 [通用 Skill 包](downloads/ye1-journal-submission-skill.zip)，解压后将完整文件夹导入或放入所用 Agent 的技能目录；WorkBuddy 用户可使用 [WorkBuddy 导入包](downloads/ye1-journal-submission-workbuddy.zip)。

根据任务使用当前 Agent 可用的检索、文件和文档工具。

## 开始使用

你可以从投稿的任何阶段开始。把下面适合你的一段话发给 Agent，并提供手头已有的稿件、资料或期刊信息即可。

### 1. 还没有选好期刊

> 我有一篇医学论文，请结合研究内容和我的投稿要求推荐合适的期刊。比较期刊范围、收录与分区、费用和审稿信息，说明推荐理由。如果是数据库研究，也请看看相关期刊近期发表的同类文章。

### 2. 已经选好期刊，准备投稿材料

> 我准备向这本期刊投稿，请查阅作者指南，按要求整理正文、图表和参考文献，准备标题页、投稿信及需要的声明。请复用我已经确认的作者信息，并把材料整理到文件夹中。

### 3. 查找推荐审稿人

> 请根据我的论文主题和方法，帮我查找合适的推荐审稿人，整理他们的研究方向、机构、相关论文和公开联系方式，并核对可查到的合作关系，供我确认。

### 4. 协助填写投稿系统

> 投稿文件和作者信息已经确认，请帮我进入期刊投稿系统，填写稿件信息、作者和声明，上传正文、图表及附件。完成后先展示投稿预览，待我确认后按我的要求继续。

### 5. 管理多篇论文

> 我有几篇论文正在准备或投稿，请帮我整理一份总览，分别记录文章、目标期刊、投稿进度、待办和截止日期。以后查到新的进展，也请更新对应记录。

### 6. 查询审稿进度并设置提醒

> 请查看这篇文章的投稿状态和可见的审稿进度，记录当前状态、变化和需要处理的事项。帮我设置定期查询，有状态变化或临近截止时提醒我。

### 7. 整理投稿邮件

> 我愿意授权连接投稿用邮箱，请整理与这些稿件相关的期刊来信，提取编辑决定、审稿意见和截止日期，并更新对应文章的进度。

### 8. 投稿材料被退回

> 期刊退回了这篇文章，请根据退回通知找出需要补充或修改的内容，先处理能够直接完成的格式和文件问题，再整理需要我确认的事项。

### 9. 收到修回意见

> 这篇文章需要修回，请把期刊决定信、完整审稿意见、原投稿稿件和相关附件整理成修回材料包，并列出期刊要求和截止日期，交给我的写作 Agent 继续处理。

### 10. 被拒后准备改投

> 这篇文章被拒了，请结合编辑意见和之前的选刊记录，帮我比较下一本适合的期刊。选定后，按新期刊要求重新整理投稿材料，并保留之前的版本。

### 11. 录用后核对校样

> 文章已经录用，请用最终录用稿对照期刊校样，检查标题、作者、单位、正文、图表和参考文献，整理需要更正或由我确认的事项。
