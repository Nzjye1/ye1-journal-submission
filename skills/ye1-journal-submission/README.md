# Ye1 医学论文投稿助手

帮助已有论文的作者选刊、按照期刊要求整理稿件和声明、复用作者档案、推荐审稿人并保留每次投稿的本地版本；还可管理多篇论文和投稿总览，按用户目标和授权协助投稿、监控、可选读取投稿邮件，处理退回或拒稿并整理录用后的校样与出版事项。学术修回整理材料供客户的写作 Agent 处理。

本 Skill 是工作指引，使用宿主实际提供的检索、文件、文档、浏览器和调度能力；不附带期刊数据库、Python 包、浏览器驱动或后台服务。各步骤可以单独使用。

安装时保留整个文件夹及引用关系；调用入口是 [SKILL.md](SKILL.md)。使用时可以提供已有论文、作者资料或目标期刊，例如：

> 帮我为这篇数据库研究选刊，比较期刊官网范围、近期数据库文章和我关心的指标。

> 请按目标期刊整理这篇论文、声明和标题页；先让我确认作者信息，准备好文件夹供我自己投稿。

> 这篇论文需要改投，请保留之前的投稿版本，用已确认资料重新整理新期刊的材料。

> 期刊要求推荐审稿人，请帮我查找合适的候选并说明匹配理由。

> 请整理我这几篇文章的投稿总览，把改投历史分开记录；查询状态后更新各篇进度。

> 请查看各篇可见的审稿进展、截止日期和监控是否正常，有需要处理的事项再提醒我。

> 我愿意连接投稿用 QQ 邮箱，请帮我整理其中与这些稿件相关的新邮件。

> 这篇文章被要求修回，请把决定信、审稿意见和原投稿文件整理成文件夹，供我的写作 Agent 使用。

> 这篇文章被拒了，请核查编辑推荐的转投期刊并结合之前的选刊建议，给我一个快速改投方案。

> 论文已经录用，请帮我检查校样，整理期刊要求和需要我确认的出版事项。

邮件是可选功能，未开启时不读取邮箱；连接器实际授权范围及宿主的数据处理以使用时的界面和服务为准。运行资料、作者档案与逐次投稿文件夹保存在用户私人本地工作目录，不放入公开 Skill。提供能力取决于实际宿主、可访问来源、用户资料和授权；准备材料不等于正式投稿，不保证期刊录用。本 Skill 中 Ye1 拥有授权权利的内容采用 [CC BY-NC 4.0](LICENSE)，具体范围与历史许可见 [说明](LICENSING.md)。
