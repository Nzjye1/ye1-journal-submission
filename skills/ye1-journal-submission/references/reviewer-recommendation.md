# 推荐或回避审稿人

期刊/投稿页面要求或提供推荐审稿人，或客户主动请求时，Agent 协助准备；期刊禁止推荐或客户明确不需要时不向系统添加。先复用客户已提供、已在本次确认的名单和限制；按期刊要求的数量与字段工作，不强制固定人数或让客户填写机器表格。客户单独请求候选名单时，即使期刊禁止或规则尚不明确，也可将查到的候选作为本地参考并说明不能直接填报。

## 先了解客户意向

本次需要准备推荐审稿人而客户尚未说明是否有自己的人选时，问一次：“您有没有自己推荐的审稿人？如果没有，我会帮您查找。”可在初次收集投稿资料或确认作者信息时顺带问，不另要求客户填专用表。本次已提供人选、已说没有或已交由 Agent 寻找时，直接复用，不重复问；只有过往名单而不清楚本次是否沿用时，简短确认。

客户有意向人选时优先核实其身份、专业匹配、机构、期刊要求的联系方式及可查证的利益关系；资料不全时先自行补查。人选不符合期刊要求或数量不足时说明原因，并自行查找合适的补充人选供客户确认。客户说没有自己的人选，就直接自行查找，无须再让客户提供名单；若客户明确表示不想推荐审稿人，则尊重其决定。尚未收到回答时，可先查找候选并继续其他工作，但不把未回答当成客户明确表示没有人选。期刊已明确禁止推荐且客户没有单独要求名单时，不必增加这个问题。

若期刊官网不同位置或官网与当前投稿页面对能否推荐的要求冲突，保留两处来源和日期，不擅自认定哪项有效；继续其他可做部分，相关名单仅供参考或待客户依据期刊当前规则核实后使用，不向期刊发信或填报冲突项。

## 寻找与核实

根据稿件研究问题、方法与专科，用必要的公开主题词检索相关论文和期刊、PubMed、Crossref 或可访问的其他来源；不把未发表全文、作者私人资料或客户身份信息输入公开搜索。选择与本研究确有相关工作的潜在专家，记录代表论文/DOI 或 PMID、研究方向和来源。

核对论文作者与专家当前机构资料是否为同一人；通过机构官网或其他可靠公开来源核对当前单位和公开的工作邮箱。未找到或无法确定就标记未知，不按姓名或机构格式猜邮箱、职位或个人信息；同名无法区分时不把候选当作已核实。

查看期刊关于审稿人独立性、同机构和合作关系等具体规则。可先检索候选专家的公开发表记录，再在本地与作者档案比较共同署名及机构，不将客户作者名单作为公开检索内容；同名无法确认、记录不全时标记未知。师生、个人、经济或其他非公开利益关系不能由未检出推定不存在。期刊无明确时间窗口时，近五年共同发表可作为参考并写明窗口，不把它当作所有期刊的硬性规则。因同机构或利益关系等不符合期刊个体要求的人不作为合格候选；证据不足、身份不明或不能排查的部分如实标记。客户已有回避名单直接使用，不擅自替作者认定某人有利益冲突。

## 与客户确认及填报

给出适合当前期刊要求的候选、研究匹配理由、机构/邮箱的来源、已查关系和未查明事项；把需客户判断的私人关系或缺失信息与其他投稿问题尽量一次询问。使用客户本次已明确确认的名单，不重复询问；尚未确认时保留候选供确认，先继续不依赖该名单的工作，不把候选冒称作者同意。无足够可信候选或未找到期刊必填邮箱时说明缺口，不能虚构以通过表单。

经本次相应确认且获授权后，按页面需要填写推荐或回避名单，并回读核对；如果需要发送邀请、邮件或其他通知，按单独授权及宿主规则处理。自行检索不等于已经推荐，填入偏好也不等于期刊会邀请或采用。
