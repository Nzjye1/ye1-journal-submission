# 作者、表单与声明

## 复用本篇资料

读取第一部分生成的材料、本次确认的作者档案和本篇事实；如果用户直接给了现有稿件或投稿资料，同样可以单独开始。按页面实际字段对应标题、摘要、关键词、文章类型、栏目、作者及单位、贡献、伦理、资金、利益冲突、数据和其他要求。必要时在本地记下“字段—已知值—来源/待确认”，不要求客户填写固定表格。

以本次确认的稿件及作者内容为准；稿件、档案和系统自动提取不一致时先识别差异，能根据本次已确认内容纠正就直接处理，事实冲突或不确定时集中询问。字段缺失不妨碍其他可以填写的部分。标题和摘要中的特殊字符、上下标、段落和关键词分隔以系统支持及实际显示为准，不随意改变科学内容。

## 作者和账号

每次使用作者档案前按[作者档案](author-facts.md)确认本次作者名单、顺序、机构及通讯作者；已有针对本次的明确确认不重新问。按实际页面核对登录人、投稿人、通讯作者及共同通讯作者，不把账号显示名自动加为作者，不因自动提取就删除或重建已有作者。按照已确认信息处理多个单位、邮箱、ORCID 和贡献；识别同名、重复作者或系统已有记录，不能确定时保留并询问。

修改通讯作者或作者关系前，阅读页面对稿件归属、访问权限和通知的影响，按已确认的作者安排及用户授权处理；若会转到客户尚无法访问的账户或触发作者邀请，说明接手路径，按宿主及相应授权继续。已有资料缺席时不臆测作者是否同意投稿或声明。

## 条件问题

系统 Yes/No、单选、多选和自由文本要与本篇真实事实、声明及期刊问题含义一致；“未知/未提供”不是 No。期刊是否把公开数据库视为研究数据，以当前问题语义与本篇事实判断，不因数据公开直接选 No。资助机构、项目号及多位资助者应逐条对应，不能为填完表单编造；系统匹配到相近机构但不能确定时请客户核对。

涉及第三方材料、预印本、开放获取、出版条款、费用或作者通知时，分清事实披露、客户选择和对外动作；只问尚未决定或未获授权的部分，不重复索要本次已经给出的决定。系统要求的信息不在材料中时明确标为待补，不能把占位符填成已确认内容。

上传或更换主稿可能使系统重新提取标题、摘要、作者和声明；在主要文件确定后重新比对，不以预填或绿色标记代表事实准确。必要时保存并回访确认。
