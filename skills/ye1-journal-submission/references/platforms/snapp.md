# SNAPP：可选经验备注

以下经验来自 2026-10-22 的 BMC Cardiovascular Disorders / Research 页面。
仅在需要时参考，其他期刊和后续页面以当前观察为准。正常操作直接按[通用指引](../execution.md)。

- **注册分流**：输入邮箱后可能进入登录或 Create account。观察到的新注册字段为姓名、
  密码及重复密码，条款和营销订阅独立。按用户资料和宿主规则处理，不默认勾选营销。
  注册后的回跳可能仍指向另一账号的旧稿件；Not Found 不足以判断注册失败，先核对身份。
- **页面与文件**：观察到 Files、Details、Authors、Declarations、Review。投稿信在 Details，
  Review 的 Files 计数可能只包含主稿与补充材料，不能只看总数判断齐全。
- **替换主稿**：已有槽位可再次上传，不必默认先删文件；多文件槽位可能会新增附件。
  主稿处理可能更新标题、摘要、作者和声明，应重新核对。实际出现过标题空格错误和
  贡献未提取的情况，按真实材料纠正，不能信任自动提取覆盖所有字段。
- **作者与声明**：当前机构限制是每位作者最多两个。独立填写的作者贡献、数据声明等
  可能替代稿内声明用于发表。使用公开数据库也属于使用研究数据，不能因此选 No。
- **保存与下载**：编辑后下载可能触发离开提示。先保留输入、确认保存，必要时另开同一
  草稿只读核对后再下载；不要因下载失败而重传。正式提交按钮可点不代表缺项已解决。
- **状态读取**：详情页可见当前状态与 Show history。区分平台更新日期和查询时间，
  邀请审稿人不等于已接受邀请或报告已返回。
