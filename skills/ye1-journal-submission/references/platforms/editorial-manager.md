# Editorial Manager：可选经验备注

以下来自 Elsevier 2026-10-03 的[官方投稿说明](https://www.elsevier.support/publishing/answer/how-do-i-submit-a-manuscript-in-editorial-manager)，非本 Skill 的真实平台实测。各期刊、文章类型及后续页面可能不同，以当前页面为准；普通步骤由 Agent 自主完成。

- 当前官方说明中投稿账号默认被设为通讯作者；变更通讯作者可能使稿件转至新通讯作者账户，原投稿人不再能继续查看或批准。变更前先核对本篇已确认的作者安排和页面的实际影响；不可用另一账户时说明如何接手。
- 系统可从主稿提取信息；作者、单位和资助条目可能需补全或重新排序，按本次确认资料核对。文件角色和合成 PDF 的顺序可能不同于上传顺序，检查最终预览。
- 官方说明的典型流程中，生成 PDF、查看 PDF 和 Approve Submission 是不同步骤；Approve 可能完成正式投稿。客户要求停在提交前时，不因按钮不叫 Submit 就误触最后步骤。
- 作者指南、表单、栏目、审稿人建议和声明分支由期刊配置；缺少本备注或实际页面不同不妨碍按当前观察执行。
