# 逐次投稿的本地版本

在客户指定的私人本地工作目录中保留原稿，并为每次新投稿/改投建立独立文件夹；同一投稿修回另建对应轮次版本。文件夹名称便于客户识别论文、期刊、日期或轮次即可，不强制统一编号、ZIP、JSON、哈希或特定应用。继续同一已有草稿时沿用对应记录，避免重复创建投稿。

编辑技术退回的材料与补正版本也独立留存；学术修回先保存[交接包](revision-handoff.md)，写作 Agent 返回后另存其修改材料及本轮实际提交版本，不覆盖旧稿。

录用后另存实际可取得的录用决定、最终录用稿、期刊校样、校样修改记录和可核实的出版版本；分别标明来源及状态，不把本地准备稿或未返回的修改冒称实际录用稿、最终校样或发表版。细节按[录用后处理](acceptance-followup.md)执行。

准备阶段保存适配后的稿件、标题页、图表、投稿信及其他附件，以及本次确认的作者顺序、单位、通讯作者、声明、目标期刊和指南来源。在本篇私人记录中写明可复用作者档案位置及本次确认快照；图稿保留原件、修改稿及来源和修改说明。事实或确认缺失的版本明确标记待补/草稿；准备完成不等于上传或提交。

当本 Skill 后续实际执行投稿时，保存与**当次实际上传**一致的文件副本、已填表单/作者/声明的必要快照和实际结果；按页面可见内容核对，能下载核验时按需核验，不能确认的部分标明未知。若最终提交前文件或表单有调整，更新本次待提交副本，保留实际提交时版本；不得把未完成上传、草稿保存或结果不明称为正式提交。不要保存密码、验证码、令牌或浏览器会话。

未来改投、换作者或修回从原稿或已存版本另存，适配新期刊并重新确认本次作者信息；不覆盖原稿及历史投稿快照。作者档案后续更新不会反向改写历史记录。已提交稿件变更作者或改投，遵守期刊要求并确认原稿状态；准备材料本身不自动授权上传、邀请作者或正式提交。

交付时指出本次文件夹位置、哪些文件可用/待补、是否实际投稿和剩余事项。系统回执或上传文件不可访问时保留已知内容及缺口，不推断成功。
