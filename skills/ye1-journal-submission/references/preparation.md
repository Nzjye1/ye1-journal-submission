# 投稿准备

根据已有论文和客户要求完成选刊、期刊适配与材料交付；只做本次要求的部分。
本 Skill 是指导，不自带期刊数据库、格式引擎、浏览器驱动或固定执行程序。

## 按任务读取

- 未定期刊或需要核对选择依据：读[选刊](journal-selection.md)。已选定期刊则跳过推荐，但仍核对当前投稿指南。
- 需要作者信息、作者变更或制作含作者的文件：读[作者档案与稿件事实](author-facts.md)。查找或建立可跨文章复用的私人作者档案，先取得客户对本次使用内容的确认；已有针对本次的明确确认即采用，不重复追问。确认前可先完成不依赖作者身份的工作。
- 排版、图稿、声明和附件：读[期刊适配与声明](formatting-declarations.md)。图稿先查找可用的原始素材并自行处理可解决的问题；仅凭真实资料完成能做的部分，未确认事实标为待补。
- 需要一并准备推荐审稿人时：读[推荐审稿人](reviewer-recommendation.md)，可在收集投稿资料时顺带询问客户是否已有想推荐的人；已经回答过则复用。
- 新投稿、改投或修回时需要本地留存：读[逐次投稿留档](submission-snapshots.md)。每次投稿建立独立文件夹，保存实际版本和信息快照；准备文件不代表已经投稿。
- 客户同时管理多篇文章或已有总览时，读[多篇文章管理](management.md)，衔接本篇资料和进度；不为单篇任务强制建立全局总览。

复用已提供的资料和明确决定，集中询问真正缺少的事实，不逐项打断客户。只读公开网页时使用必要主题词，不把完整未发表稿件、作者隐私或患者信息投入公共搜索。期刊政策、指标、先例和宿主工具都以本次实际可读、可核验的结果为准。

同时提供预印本、发表版或其他稿件版本时，先辨认本次处理的是哪一版；按来源保留版本，不能把不同版本的作者、方法、数据和结果混在一起。实际处理版本不明确时，先做不依赖该决定的工作，再请客户确认。

交付普通文件夹及简短说明：目标期刊和要求来源、已有选刊记录位置、各文件用途、实际修改与投稿状态；按[客户待办](records.md)区分已完成、Agent 可继续处理及确需客户处理的事项。缺资料、确认或工具时，先交付已能完成的部分；未解决文件及其预览明确标注待补，不能声称可直接上传。
