# 期刊适配、声明与附件

## 查官方要求

读取目标期刊当前官网与本篇文章类型对应的作者指南和政策正文，记录来源、日期与具体要求；搜索摘要、跳转首页或无来源模板不能代替指南。区分初投与录用后、必需与建议、正文/标题页/单独附件/系统表单。官网未说明、要求互相冲突或无法访问时标记缺口，不把常见习惯当成期刊规定。

## 排版和内容保护

保留客户原稿，另存期刊适配版本；使用宿主具备的文档编辑能力，按适用要求处理标题与作者、摘要/关键词、层级、字体行距、页码、引用、图表和附录。调整引文或图表编号时同步核对正文引用；核对数值、方向、表格、图注与参考文献条目不丢失。未经用户授权不实质改写研究方法或结果、不虚构文献，不为符合图件规格伪造像素或 DPI。引用格式整理与事实性参考文献验证分别报告。

期刊指定全稿字体、字号或行距时，同时核对题目、各级标题、正文、表格和声明，防止文档主题样式覆盖指定值；没有要求时避免套用装饰性颜色或线条。预览渲染如因环境字体缺失而替换，说明实际显示情况，不将文件中的字体设置直接当作渲染通过。

匿名稿按期刊要求检查正文、文件名、文档属性、批注、修订及图表内身份信息；实名标题页单独处理。图表/补充材料按期刊的文件角色、尺寸和格式准备。报告清单只在适用且完成逐项核对后标记完成。

## 图稿处理：先找来源并自行完成

核对期刊对图件格式、分辨率、尺寸、颜色、面板、数量、图注及文件角色的实际要求，并检查正文引用顺序。发现文字遮挡、标签与正文不一致、图号错位或格式不合要求时，不只列给客户：先在客户已提供或授权的稿件目录、清单和明确指向的研究资料中查找对应的可编辑图源、矢量图、绘图脚本和汇总数据；确认与本稿和图件对应，不扫无关目录。优先使用客户已有素材与宿主现成工具，在本次新版本文件夹或临时副本中处理，不覆盖原图或原始研究文件，也不把分析脚本指向会覆盖原项目的输出位置。

根据可核实的原图、图注、正文及研究记录，自行处理文字遮挡、可证实的标签或编号不一致、版面、图例、多面板文件拆分/合并及无损格式转换等可完成的部分。拆分或重新编号后同步调整图注、正文引用和图表总数；期刊允许保留组合面板时不必强拆。优先从可编辑源或可信汇总数据重新导出，保留数值、坐标范围、曲线、组别、颜色含义和研究结论；不凭图片猜测重建数据，不改变统计结果，不把简单放大或修改元数据当作提高原始分辨率。

先核对图源对应关系，再检查导出后的实际图像或预览：文字与图形是否清晰、内容与原稿及图注是否一致、数字和面板是否完整、格式是否符合期刊。记录使用的源文件、图号对应和修改内容，让作者审阅。来源缺失、信息冲突、图内含义无法判断、需要新增分析或宿主无法可靠处理时，保留原图并说明具体缺口和已尝试的办法，集中请求必要的源文件或科学事实；不要声称已修好，也不要替作者作研究判断。优先使用汇总资料；如确需患者级数据，先确认其可访问并按客户要求在本地完成去标识处理。

**后续图像处理接口（预留）**：将来客户指定的论文图像处理 Skill 或 Agent 已可用并要求衔接时，可交接本篇需要的图稿及可用源文件、期刊要求、修改事项和需要保留的科学内容；收到结果后仍按本节核对，并保留原稿与新版本。具体工具和功能关联由客户后续确定；当前不绑定、自动调用或要求安装任何图像处理工具。

## 声明与辅助材料

根据官网要求和[本篇稿件明示或已确认的事实](author-facts.md)，为本篇草拟适用的伦理、知情同意、发表同意、资助、利益冲突、作者贡献、数据可用性、登记、致谢或 AI 使用等声明，放在期刊指定位置；是否需要及具体措辞以期刊与真实事实为准。可使用事实支持的英文或中文表述，不能擅自决定政策选项或编造机构、编号、资金和作者承诺。先用已知事实完成，缺项集中一次问客户；待确认内容标记清楚，不将占位符或未知值写成“无”。

根据要求准备标题页、投稿信和其他附件；只使用已确认的作者及稿件信息。核对正文、标题页、声明、投稿信和拟填表信息互相一致。资料缺失时继续做不依赖缺失事实的工作，把未完成文件与可用文件区分开。

## 验证与交付

交付真实可编辑文件，而不是只描述计划；有渲染/预览能力时检查最终页面的表格、图注、换页、字符和截断。无编辑或渲染工具时交付已经完成的材料或具体修改清单，明确未生成/未视觉检查的部分。说明要求来源、已改内容、待补事实、文件位置以及是否已投稿；不要把准备完成称为投稿成功。
