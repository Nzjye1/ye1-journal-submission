# 录用后的校样与出版事项

## 核对决定并整理下一步

客户要求处理录用后事项，或已约定监控后继续时，先复用客户给出的决定信、已授权可见的期刊系统和已启用邮箱，核对文章、期刊、稿号、决定原文及时间。区分正式录用、附条件决定、校样中和已发表；只能看到状态或客户转述时注明来源及缺口，不推断录用条件已满足。只要求当前处理确需的资料，期刊尚未提供校样或其他文件时记录等待，不反复催客户提供不存在的材料。

根据实际通知和期刊页面整理待处理事项及截止日期：可能包括校样、作者信息、开放获取和费用、出版协议、发票或付款、在线发表信息等；实际没有出现的项目不编造为期刊要求。日期精度、来源和时区未知照实标记。费用按[选刊](journal-selection.md)保留原币并提供可核实的人民币参考；没有真实账单不假称付款到期或金额已确定。尽量先自行整理，在[客户待办](records.md)中简短区分可继续处理、等待期刊及必须由客户决定的事项。

## 校样核对与交付

取得校样后，优先与可核实的最终录用稿及图表、已确认作者信息对照；分别检查标题、作者及单位、通讯信息、摘要、正文、图表及图注、参考文献、基金与声明等期刊转换后可能改变的内容。实际可见时核对页码与位置，记录差异、依据和拟修正内容；缺少录用稿、图件、附件或可用预览时明确未核对的范围，不把最近本地草稿冒称最终录用稿或声称已全面校对。只对照可取得的资料，不擅自改写科学结果或凭校样推测事实。

Agent 尽量完成能依据既有材料确认的查错、文件整理和纠错意见草稿；涉及科学含义、署名、基金、声明等事实不清的事项集中请作者确认。校样纠正方式以期刊当前要求为准；客户明确要求并授权发回或上传时，按实际页面及宿主规则执行，检查结果并保留实际发回版本，不能把本地纠错稿说成已经提交。用户没有授权对外发送时，交付可审阅的修改清单或文件。

开放获取方式、费用、版权或许可条款涉及客户决定；说明期刊实际要求及已知金额，缺少决定时集中询问，不默认选择、不替作者作出承诺。付款、签署及对外发信按客户明确授权与宿主规则执行，已获得同一决定和授权时不反复询问。

## 保存与更新状态

在本篇私人投稿目录中按[逐次留档](submission-snapshots.md)保留可取得的录用通知、最终录用稿、原校样、核对或纠错记录、实际发回的文件与可核实的出版版本；标明来源、时间、可取得情况和当前状态，保留原件。若客户已有多篇总览，同步对应文章的录用、校样、截止及出版进度；系统或论文页面出现可核实的在线发表日期、DOI 或链接时再记录，录用不等于已发表。只读监控发现录用时先报告和记录；客户要求或已有约定后再继续相应处理。
